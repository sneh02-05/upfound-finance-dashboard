UPFOUND — PERSONAL FINANCE DASHBOARD

PROJECT DESCRIPTION
UpFound is a frontend personal finance tracker designed to help users manage income, expenses, and savings goals through a clean, modern dashboard.

FEATURES
- Interactive financial dashboard
- Add and delete income and expense transactions
- Filter transactions by type
- Automatic balance, income, and expense calculations
- Create and manage savings goals
- Track savings progress
- Data persistence using browser localStorage
- Responsive dark-themed interface
- Separate landing page with navigation to the dashboard

TECHNOLOGIES USED
- HTML5
- CSS3
- JavaScript
- Browser localStorage

HOW TO RUN
1. Extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open landing.html using Live Server.
4. Click Get Started to access the dashboard.

IMPORTANT NOTE
This is a frontend demonstration project. It does not connect to real bank accounts or financial services. Data is stored locally in the browser.
